## A0. 代理配置（2026-09-21 实测可用，优先用这条路径）

代理地址：**`http://192.168.2.47:7897`**（即本机的 Clash/V2Ray 类 mixed 端口，103 经 192.168.1.120 可达，ping 1.8ms）

```bash
# A0-1 会话级（最简单，临时用）
export http_proxy=http://192.168.2.47:7897
export https_proxy=http://192.168.2.47:7897

# A0-2 git 持久化（只影响 git，不污染全局网络）
git config --global http.proxy  http://192.168.2.47:7897
git config --global https.proxy http://192.168.2.47:7897
# 取消：git config --global --unset http.proxy; git config --global --unset https.proxy

# A0-3 apt 持久化（装 ROS 包时有用）
echo 'Acquire::http::Proxy  "http://192.168.2.47:7897";'  | sudo tee /etc/apt/apt.conf.d/01proxy
echo 'Acquire::https::Proxy "http://192.168.2.47:7897";'  | sudo tee -a /etc/apt/apt.conf.d/01proxy

# A0-4 连通性自检
curl -s -x http://192.168.2.47:7897 -o /dev/null -w "github=%{http_code} %{time_total}s\n" https://github.com
# 期望：github=200 ~1.8s
```

实测记录：

| 项 | 结果 |
|---|---|
| `ping 192.168.2.47` | 1.7~2.0 ms，0% 丢包 |
| TCP 7897 | OPEN |
| HTTP 代理 → github.com | `200`，conn 0.002s，total 1.8s |
| SOCKS5 代理 → github.com | `200`，total 4.8s（能用但慢，优先 HTTP） |
| 代理 → raw.githubusercontent.com | `200`，1.5s |
| **代理 → git clone 全仓** | **成功，4m29s，122M，commit `348e8a5`** |

## B. 依赖自检脚本（先本机写文件，再 scp，避免引号坑）

本机创建 `check.sh`：

```bash
#!/bin/bash
# SCAN-Planner 部署前依赖自检（ROS 1 Noetic 视角）
echo "=== 系统 ==="
lsb_release -d
uname -m; nproc; free -g | head -n 2
df -h / | tail -n 1

echo "=== 编译器 ==="
gcc --version | head -n 1; cmake --version | head -n 1

echo "=== 库 ==="
dpkg -l | awk '$1=="ii" && ($2 ~ /^libeigen3-dev$|^libpcl-dev$|^libopencv-dev$|^libarmadillo-dev$/) {print $2, $3}'
ls /usr/share/cmake-*/Modules/FindArmadillo.cmake
dpkg -l | awk '$1=="ii" && $2 ~ /^libboost-(filesystem|iostreams|program-options|serialization|system)-dev$/ {print $2}'

echo "=== ROS 1 组件 ==="
for p in roscpp rospy std_msgs geometry_msgs nav_msgs sensor_msgs visualization_msgs \
         tf message_filters message_generation cv_bridge pcl-ros pcl-conversions \
         cmake-modules roslaunch robot-state-publisher rviz; do
  s=$(dpkg-query -W -f='${Status}' ros-noetic-$p 2>/dev/null)
  printf "%-28s %s\n" "ros-noetic-$p" "${s:-MISSING}"
done

echo "=== ROS 环境 ==="
ls /opt/ros
echo "AMENT_PREFIX_PATH=[$AMENT_PREFIX_PATH]  (应为空)"
echo "ROS_VERSION=[$ROS_VERSION]  (应为 1)"
```

```bash
scp check.sh lite3-f20-1-103:/home/test/scan_planner/scripts/check.sh
ssh lite3-f20-1-103 "chmod +x /home/test/scan_planner/scripts/check.sh && bash /home/test/scan_planner/scripts/check.sh"
```

**2026-09-21 实测结果**：上述全部 `install ok installed`，`libarmadillo-dev 9.800.4`、`libpcl-dev 1.10.0`、`libopencv-dev 4.2.0`、`libeigen3-dev 3.3.7`、Boost 五组件齐全；仅 `libglfw3-dev` 未装（不影响默认 CPU 构建）。

## F. 回滚与清理

本项目**不安装任何系统包、不改 systemd、不改 `~/.bashrc`**，因此回滚就是删目录：

```bash
# F1 只清编译产物（保留源码，最常用）
ssh lite3-f20-1-103 "rm -rf /home/test/scan_planner/build /home/test/scan_planner/devel"

# F2 完全撤出（保留 note 文档）
ssh lite3-f20-1-103 "cd /home/test/scan_planner && rm -rf src build devel logs scripts SCAN-Planner-src.tar.gz"

# F3 连作业空间一起删（注意：会删掉本文档）
# ssh lite3-f20-1-103 "rm -rf /home/test/scan_planner"
```

注意：

- `devel/setup.bash` 若被写进 `~/.bashrc` 才会产生持久影响 —— **本方案不写**，每次用 `scripts/env.sh` 显式加载。
- ROS 1 的 `roscore` 默认占 11311 端口，与现有 ROS 2（foxy）不冲突；但**同时 source 两套 ROS 会串环境**，所以所有 ROS 1 操作必须经 `env.sh`。
- 若编译期临时停过 `lite3-monitor.service`，收尾务必确认已恢复：`systemctl is-active lite3-monitor` 应为 `active`。

## G. 排障速查

| 现象 | 原因 | 处置 |
|---|---|---|
| `catkin_make` 报 `Could not find ... catkin` | 环境没切到 noetic | 先 `source scripts/env.sh`，确认 `rosversion -d` = noetic |
| 编译中途 `cc1plus: internal compiler error: Killed` | OOM | 降并发 `-j1`，确认 swap 在线，停掉占用内存的服务后重试（增量编译会续跑） |
| `find_package(Armadillo)` 失败 | 缺 dev 包或 CMake 模块 | 实测已装；若异常走离线 deb 补装 |
| `FATAL_ERROR ... glfw3` | 误开 `-DUSE_GPU=ON` | 去掉该选项，用 CPU 版 |
| `roslaunch` 报 `map_generator/mockamap` 找不到 | 解包层级错误 | 确认 `/home/test/scan_planner/src/simulator/{map_generator,mockamap}` 存在 |
| 仿真起不来但无报错 | roscore 未起 / ROS_MASTER_URI 不对 | `rosnode list`、`echo $ROS_MASTER_URI`；本机连 103 调试需 `ROS_IP` 双向可达 |
| `/cmd_vel` 一直为 0 | 没收到目标点，或 FSM 未进入 EXEC | 检查 `/move_base_simple/goal` 的 `frame_id` 是否为 `world`，并看 `scan_planner_node` 日志 |
| 想用 ROS 2 版 | `ros2-community` 分支要求 22.04 + Humble | 103 是 20.04 + Foxy，不可用；需自行回迁或走 ros1_bridge |
