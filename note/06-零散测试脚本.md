# 06 · 零散测试脚本（RealSense / UDP / RTSP）

**适用场景**：硬件自检、协议调试、临时验证。这些脚本不常驻、不需要部署，按需手工跑。

## 一、RealSense 相机测试

路径：`/home/test/realsense_test/`

| 文件 | 作用 |
|---|---|
| `test_rgb.py` | 彩色流采图，输出 `rs-save-to-disk-output-Color.png` + metadata csv |
| `test_depth.py` | 深度流采图，输出 `rs-save-to-disk-output-Depth.png` + metadata csv |
| `test_pointcloud.py` | 点云生成与保存 |
| `test.bag` | 录制数据（**402 MB，不入库**） |

```bash
cd /home/test/realsense_test
python3 test_rgb.py
python3 test_depth.py
python3 test_pointcloud.py
```

依赖：`pyrealsense2`（`python3 -m pip install pyrealsense2`，或用 apt `ros-noetic-realsense2-camera`）。

验证：当前目录出现对应 `*.png` 与 `*.csv`，且 png 非全黑。
常见问题：
- `No device connected` → 换 USB3 口（RealSense 对 USB2 带宽敏感）；
- `ImportError: pyrealsense2` → 装包；
- 权限不足 → `sudo usermod -aG video ysc` 后重登。

## 四、IEEE 754 浮点速查（控制协议解析用）

`0.00→0000000000000000`、`0.05→9A9999999999A93F`、`0.10→9A9999999999B93F`、
`0.20→9A9999999999C93F`、`0.50→000000000000E03F`、`1.00→000000000000F03F`；
负号只把尾字节 `3F` 换成 `BF`（如 `-0.05→9A9999999999A9BF`）。

## 回滚方式

这些脚本只读采集，不写系统配置；唯一副作用是生成的 `*.png`/`*.csv`/`*.bag`
可直接删除，以及调试进程占用 43897 —— 用完 `Ctrl-C` 退出即恢复。
