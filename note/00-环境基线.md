# 00 · 新主机环境基线

**适用场景**：拿到一台全新的 lite3 感知导航主机，在部署任何功能之前先把环境对齐到 103 的水平。

## 操作步骤

### 1. 核对基线（任何一项不符，先补齐再往下走）

```bash
cat /etc/os-release | head -2      # 期望 Ubuntu 20.04.6 LTS
uname -r                           # 期望 5.10.120-tegra
cat /etc/nv_tegra_release          # 期望 R35 REVISION: 4.1, BOARD: t186ref
ls /opt/ros                        # 期望同时有 noetic 与 foxy
python3 --version                  # 期望 Python 3.8.10
nproc && free -g | head -2         # 期望 6 核 / 6 GiB
```

### 2. 装 ROS1 侧依赖（SCAN-Planner 需要）

```bash
sudo apt-get update
sudo apt-get install -y ros-noetic-desktop-full python3-catkin-tools \
  libeigen3-dev libpcl-dev libopencv-dev libarmadillo-dev libglew-dev
sudo apt-get install -y ros-foxy-ros1-bridge      # ROS1↔ROS2 桥接
```

### 3. 装 Python 依赖

```bash
python3 -m pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple
python3 -m pip install ultralytics tensorrt pycuda
```

### 4. 建工作区并设权限

```bash
sudo mkdir -p /home/test && sudo chown -R ysc:ysc /home/test
mkdir -p /home/test/{note,logs}
```

## 关键配置文件路径

| 文件 | 作用 |
|---|---|
| `/opt/ros/noetic/setup.bash` | ROS1 环境（SCAN-Planner 用） |
| `/opt/ros/foxy/setup.bash` | ROS2 环境（`~/.bashrc` 默认加载） |
| `~/.bashrc` | 默认 source foxy，跑 ROS1 前必须隔离 |
| `/etc/apt/sources.list.d/*.list` | apt 源（**不要用清华 ubuntu-ports，实测 403**） |
| `/home/test/scan_planner/scripts/env.sh` | ROS1 环境隔离脚本 |

## 验证方法

```bash
source /opt/ros/noetic/setup.bash && rosversion -d    # 期望 noetic
source /home/test/scan_planner/scripts/env.sh && echo $ROS_DISTRO   # 期望 noetic
source /home/test/scan_planner/scripts/env_restore.sh && echo $ROS_DISTRO  # 期望 foxy
python3 -c "import cv2, numpy; print(cv2.__version__)"
```

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `apt-get update` 退出码非 0 且报 403 | 清华 `ubuntu-ports` 镜像源异常 | 换 `ports.ubuntu.com` 或 ustc 镜像 |
| 跑 ROS1 命令报 `AMENT_PREFIX_PATH` 串味 | 默认 source 了 foxy | 先 `source /home/test/scan_planner/scripts/env.sh` |
| `source env.sh` 报 `unbound variable` | 脚本配了 `set -u`，ROS 的 setup.bash 里有未设变量 | 前后用 `set +u` / `set -u` 包起来 |
| pip 装 tensorrt 失败 | Jetson 的 TensorRT 来自 JetPack，不走 pip | 用 `python3 -m pip install tensorrt` 会失败时改用系统包 `python3-libnvinfer` |
| 编译大型 C++ 项目时系统卡死 | 内存只有 6 GiB | 编译统一用 `-j2`，不要 `-j6` |

## 回滚方式

- 环境脚本：`source /home/test/scan_planner/scripts/env_restore.sh`（会自动读取 `scan_planner/logs/env_backup_*.sh` 快照精确复原）。
- apt 装错包：`sudo apt-get remove --purge <包名> && sudo apt-get autoremove`。
- pip：`python3 -m pip uninstall <包名>`。
