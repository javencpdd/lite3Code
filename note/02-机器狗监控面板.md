# 02 · 机器狗监控面板（Lite3 Robot Monitor）

**适用场景**：在 103 上旁路抓取机器狗 UDP 状态包，通过 Web 面板实时查看姿态/里程计，并可下发控制指令。

## 架构要点

- UDP **43897 已被 `transfer_ros2` 独占**，本服务**不 bind 该端口**，改用 `AF_PACKET` 链路层旁路抓包（`sniff` 模式），与 `transfer_ros2` 零冲突。
- 服务以 `ysc` 运行，仅授予 `CAP_NET_RAW` 最小权限（不跑 root）。
- 后端 FastAPI + uvicorn，前端静态产物由 `frontend/dist` 提供。

## 操作步骤

### 1. 打包（排除 node_modules）

```bash
cd /home/test/lite3_robot_monitor
bash deploy/pack.sh                       # 产出 lite3-monitor-deploy.tar.gz
scp lite3-monitor-deploy.tar.gz ysc@<目标机>:/tmp/
```

### 2. 安装（目标机上）

```bash
cd /tmp && tar xzf lite3-monitor-deploy.tar.gz
PIP_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple \
  sudo -E bash lite3_robot_monitor/deploy/install.sh /home/test/lite3_robot_monitor
```

`install.sh` 会自动替换单元里的占位符：`__DIR__`、`__USER__`、`__GROUP__`、`__HOME__`、`__HTTP_PORT__`、`__ROS_PORT__`、`__VENV_PY__`、`__MONITOR_SVC__`、`__ROS_NODE__`，无需手改。

### 3. 常用运维

```bash
systemctl status lite3-monitor
sudo systemctl restart lite3-monitor
sudo systemctl daemon-reload                  # 改单元后必做
journalctl -u lite3-monitor -f
```

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 抢走 43897 导致 `leg_odom2`/`/imu/data` 断流 | 用了 `bind` 模式 | 改 `LITE3_UDP_MODE=sniff`（默认 auto 也会自动退回 bind，需显式指定） |
| 服务起不来，报权限不足 | `AF_PACKET` 需要 `CAP_NET_RAW` | 保留 `AmbientCapabilities=CAP_NET_RAW`；老内核不支持则改 `User=root` |
| 依赖找不到（`ModuleNotFoundError`） | pip 装到 `~/.local` | 单元里必须有 `Environment=HOME=<家目录>` |
| 改了 service 不生效 | 没 reload | `sudo systemctl daemon-reload && sudo systemctl restart <服务>` |
| `lite3-monitor2` 反复失败 | 指向的 `/home/test/monitor2` 目录已删除 | `sudo systemctl disable --now lite3-monitor2` 并删除单元 |
| 方向反了（前进变后退） | 固件与文档参考系不一致 | 改 `LITE3_CTRL_INVERT_VEL_X/Y/YAW=true`，不改代码 |
| 主服务停了桥接还在跑 | 生命周期未绑定 | 单元里已用 `BindsTo` + `PartOf` 绑定，勿删 |

## 回滚方式

```bash
sudo systemctl disable --now lite3-monitor lite3-ros-bridge
sudo rm -f /etc/systemd/system/lite3-monitor.service /etc/systemd/system/lite3-ros-bridge.service
sudo systemctl daemon-reload
```

数据无落盘，删服务即完全回滚；重装前建议备份单元：
`sudo cp /etc/systemd/system/lite3-monitor.service{,.bak-$(date +%Y%m%d)}`。
